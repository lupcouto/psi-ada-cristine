# 🧠 Ada Cristine | Psicóloga

Landing page desenvolvida para a apresentação profissional, com foco na divulgação de seus serviços de atendimento psicológico e avaliação neuropsicológica para crianças, adolescentes e jovens adultos.

O projeto foi desenvolvido com o objetivo de criar uma presença digital profissional, reunindo informações relevantes sobre a psicóloga, seus atendimentos e o funcionamento das sessões em uma interface intuitiva, acolhedora e responsiva.

---

## 🌐 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## 💡 Sobre o projeto

O site funciona como uma vitrine digital do trabalho da psicóloga, permitindo que visitantes conheçam sua atuação profissional, compreendam as modalidades de atendimento e encontrem orientações antes de agendar uma sessão.

A página apresenta informações sobre a abordagem terapêutica utilizada, os atendimentos para diferentes faixas etárias e o processo de avaliação neuropsicológica, além de uma seção de dúvidas frequentes para facilitar o acesso às principais informações.

Durante o desenvolvimento, foram aplicados conceitos de desenvolvimento Front-end, organização de conteúdo, estilização de interfaces, responsividade e interatividade, buscando proporcionar uma experiência de navegação clara e agradável em diferentes dispositivos.

---

## ✨ Funcionalidades

- Apresentação da psicóloga e de sua atuação profissional;
- Divulgação dos atendimentos psicológicos presenciais e on-line;
- Apresentação dos serviços de avaliação neuropsicológica;
- Informações sobre atendimentos para diferentes faixas etárias;
- Seção de dúvidas frequentes sobre sessões e avaliações;
- Integração com WhatsApp para contato e agendamento;
- Link para acesso ao Instagram profissional;
- Navegação entre as seções da página;
- Layout responsivo para desktop, tablet e smartphone.
